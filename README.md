# attain-your-focus
## Overview
attain-your-focus is a notification management application designed to help users prioritize and focus on important tasks. The application provides a user-friendly interface for managing notifications, allowing users to categorize, filter, and take actions on notifications.

## Core Capabilities
* Notification management: The application allows users to view, categorize, and take actions on notifications.
* Priority management: Users can prioritize notifications based on their importance and urgency.
* Smart actions: The application provides smart actions such as copying OTP, setting reminders, and adding events to the calendar.
* Filtering: Users can filter notifications based on various criteria such as app, priority, and importance.

## Architecture
The application is built using Next.js, TypeScript, Tailwind CSS, Vite, and Jest. The frontend is composed of various components, including the AppIcon, BottomNav, and NotificationRow. The application uses a modular structure, with separate modules for components, screens, hooks, lib, pages, and tests.
